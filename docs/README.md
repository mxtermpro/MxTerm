## About

MXterm Pro is a desktop app for macOS, Windows and Linux: real terminal panes, a Control Room for AI coding agents, and SSH/SFTP in one native workspace. Download it at [mxterm.net/download](https://mxterm.net/download). Questions: [Discussions](https://github.com/mxtermpro/Mxterm/discussions) or support@mxterm.net.
